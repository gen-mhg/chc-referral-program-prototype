Why Native Share

Feedback: David, Jaga, and Artem agreed the programme should use native share rather than limiting to WhatsApp.

WhatsApp still dominates in HK (~90% penetration) but users also share via Telegram, Signal, Messages, and AirDrop. Native share lets the OS handle app selection — no assumptions needed.

Desktop fallback: Copy-link button when navigator.share is unavailable.

v1 — Step 4

Backend → TalonOne (2-step)

On account creation, backend sends two calls to TalonOne: (1) close the friend's session with the referral code to validate the referral, then (2) fire an event to register the achievement on the advocate's profile.

Backend → TalonOne Step 1: Session Close

PUT /v2/customer_sessions/{id}
{
  "referralCode": "SC7X2K",
  "state": "closed"
}

Closing the session with the referral code triggers TalonOne's native referral validation. Returns referral success + code use count via webhook.

Backend → TalonOne Step 2: Achievement Event

POST /v2/events
{
  "type": "chc_event",
  "profileId": "advocateOwnerId",
  "attributes": {
    "source": "referral-listener",
    "transactionReferenceId": "{{guid}}",
    "referredUserId": "friendOwnerId",
    "referralCompletionDate": "2026-...",
    "referralCount": 1
  }
}

Fires on the advocate's profile. Milestone rule evaluates achievement progress → webhook returns badge status.

TalonOne Ledger

TalonOne is the source of truth:

• Session close → referral attributed to advocate

• Achievement event → L1 progress = 1/1 → award badge

• Badge: "Credit Hero Champion" Level 1
